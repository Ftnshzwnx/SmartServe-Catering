# SmartServe-Catering

SmartServe Catering is a premium catering management system built with Laravel, Vue.js (Inertia.js), and Tailwind CSS. It supports dynamic menu customization, budget planning, shopping carts, event bookings tracking, and bilingual (English and Bahasa Melayu) support.

## Features

- **Premium UI Redesign**: Beautiful minimalist design styled with curated HSL palettes (Sage Green, Oatmeal, Sand, Charcoal).
- **Bilingual Support**: Dynamic translation toggling (EN/BM) persisting via local storage.
- **Budget Planner**: Custom package recommendations based on budget and guest parameters.
- **Catering Customs**: Flexible guest headcount adjustments and add-on dish selections.
- **Milestone Tracker**: Real-time progress monitoring from deposit submission through to event completion.
- **Invoice & Receipt PDF Generator**: High-fidelity custom invoices optimized for printing.

## Technology Stack

- **Backend**: Laravel
- **Frontend**: Vue 3, Inertia.js, Vite
- **Styling**: Tailwind CSS
- **Database**: MySQL / SQLite
